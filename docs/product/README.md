## Product Summary

Shree Shivaya Hospital needs a modern, trustworthy, and easy-to-use website that helps patients understand the hospital, explore services and facilities, read health content, and request appointments. Hospital staff need a simple admin panel to manage blog posts and appointment requests.

## Reference Direction

The attached reference images establish the visual direction: large hospital imagery, generous white space, rounded image cards, soft blue/teal medical accents, pill-style navigation, clear black primary CTAs, and a calm premium healthcare feel.

The final site should adapt this direction for Shree Shivaya Hospital without copying generic marketplace language or pretending to be a hospital discovery platform.
