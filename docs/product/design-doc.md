# Design Direction

## Design Goal

Design a hospital website that feels modern, trustworthy, calm, and easy to use. The visual experience should feel premium enough to build confidence, but not so experimental that it reduces clarity for patients and families.

## Reference Interpretation

The provided reference images suggest these useful patterns:

- Large immersive hero image
- Rounded container shapes
- Pill-style navigation and buttons
- White and light grey breathing room
- Soft blue sky and hospital imagery
- Image-led facility cards
- Strong black primary CTA buttons
- Minimal, confident typography
- Floating trust indicators and badges

For Shree Shivaya Hospital, the design should use this premium healthcare feeling while keeping the language and content specific to one real hospital.

## Visual Principles

- Trust before decoration.
- Appointment actions must be obvious.
- Medical information must be readable at a glance.
- White space should make the experience feel calm, not empty.
- Photography should feel real, clean, and credible.
- Rounded cards and pill elements should soften the interface without making it playful.
- Motion, if used, should be subtle and not distract from care information.

## Brand Feel

The site should feel:

- Modern
- Trustworthy
- Clean
- Calm
- Professional
- Compassionate
- Local and accessible
- Premium but not flashy

The site should not feel:

- Generic template-like
- Overly corporate
- Overcrowded
- Loud or sales-heavy
- Like a hospital marketplace
- Like an app landing page with no medical credibility

## Color Palette

### Primary Colors

- Deep medical blue: `#0B4F8A`
- Calm sky blue: `#DDF2FF`
- Trust teal: `#3AB7A5`

### Neutral Colors

- Soft white: `#FAFAF7`
- Light grey: `#EEF1F3`
- Border grey: `#DDE3E8`
- Primary text: `#101010`
- Muted text: `#5F6B76`

### CTA Colors

- Primary CTA: `#050505` or deep navy
- Primary CTA text: `#FFFFFF`
- Secondary CTA: white with soft border
- Success/health accent: teal or green

## Typography

Typography should be clean, readable, and modern.

Recommended font direction:

- Headings: modern sans-serif with confident spacing
- Body: highly readable sans-serif

Suitable font families:

- Inter
- Manrope
- Plus Jakarta Sans

Type behavior:

- Large headings on desktop
- Short line lengths for paragraphs
- Comfortable mobile text sizing
- Clear visual distinction between headings, labels, helper text, and body copy

## Layout Direction

The landing page should use large calm sections with strong content blocks.

Page sections may include:

- Hero
- About
- Services
- Facilities and amenities
- Doctors and staff
- Why choose us
- Blog preview
- Testimonials or trust section
- Appointment CTA
- Contact/footer

The page should not feel like a directory of endless cards. Each section should have a clear purpose and enough spacing to be scanned easily.

## Hero Design

The hero should be the strongest visual moment.

Recommended treatment:

- Large rounded image container
- Hospital or healthcare image as the main visual
- Navigation integrated cleanly above or within the hero area
- Primary CTA: Book Appointment
- Secondary CTA: Call Now or Explore Services
- Small trust badges for emergency care, patient care, experience, or facilities if verified

Hero copy should be direct and reassuring.

Example direction:

"Modern Healthcare with Compassion at Its Core"

Supporting copy:

"Shree Shivaya Hospital provides dependable care with experienced doctors, attentive staff, and facilities designed for patient comfort and safety."

## Card Design

Cards should use:

- Rounded corners
- Soft shadows or light borders
- Real images when possible
- Short labels or badges
- Clear headings
- Minimal supporting text
- CTA arrows only where action is useful

Facility cards can be more visual. Service cards can be clearer and more informational.

## Button Design

Primary buttons:

- Rounded pill shape
- Black or deep navy fill
- White text
- Optional arrow icon
- Strong hover/focus state

Secondary buttons:

- White or transparent background
- Soft border
- Dark text
- Rounded pill shape

Critical CTAs:

- Book Appointment
- Call Now
- View Services
- Read Blog

## Form Design

Appointment forms should be simple and calm.

Form rules:

- Do not overwhelm users with too many fields.
- Use clear labels, not only placeholders.
- Keep required fields obvious.
- Use large mobile-friendly fields.
- Show plain-language validation messages.
- Show a reassuring success state after submission.

## Admin UI Design

The admin panel should prioritize clarity over decoration.

Admin UI should use:

- Simple dashboard cards
- Clear tables or lists
- Search and filters
- Status badges
- Straightforward edit screens
- Clear save/publish actions

Admin UI should avoid:

- Heavy animation
- Decorative layouts
- Complex nested navigation
- Hidden important actions

## Imagery Direction

Preferred imagery:

- Real hospital exterior
- Reception or waiting area
- Patient rooms
- Doctors and staff portraits
- Equipment/facilities
- Clean care environments

Fallback imagery should be realistic and not overly staged.

Avoid:

- Generic smiling doctor stock images where possible
- Unrealistic AI medical images
- Images that show unsafe clinical practices
- Crowded or visually noisy photos

## Copy Tone

The copy should sound:

- Compassionate
- Clear
- Reassuring
- Professional
- Local and human

Avoid:

- Overpromising outcomes
- Heavy medical jargon
- Fear-based language
- Generic claims like world-class unless verified

Example tone:

"Care that is easy to access, clearly explained, and delivered with compassion."

## Responsive Behavior

Mobile experience is critical.

Mobile requirements:

- Appointment CTA remains easy to access.
- Navigation is simple and obvious.
- Hero text remains readable over or near images.
- Cards stack cleanly.
- Forms are easy to complete with thumbs.
- Phone number CTA is easy to tap.

## Accessibility Direction

- Maintain high contrast for text and CTA buttons.
- Use visible focus states.
- Do not rely on color alone for status.
- Make forms accessible with labels and errors.
- Use descriptive alt text for hospital, doctor, and facility images.
- Keep animations reduced when the user prefers reduced motion.
